PowerCenter → dbt explainer

Glossary

Our shared language. One word per idea, used the same way in code, tests, the README and our chats. This is what domain-driven design calls a ubiquitous language.

Words that clash. PowerCenter and dbt use some of the same words for different things. Say which side you mean every time:

Source: say PC Source or dbt source. Target: say PC Target; in dbt, a target is an environment like dev. Expression: say Expression transformation (the box) or port expression (the formula). Test: say data test (dbt) or unit test (ours). Link: only between workflow tasks; between ports it's a connector.
