The input XML

What's inside FLOWLINE_DEMO_JAFFLESHOP.xml, level by level, and the problems we found in it.

Your summary is right. PowerCenter reads data from PC Sources, a mapping applies transformations, and the result is written to PC Targets. Three things to add:

  1. The XML doesn't run anything. It is an export, a saved copy of the design. The PowerCenter server is what runs it.
  2. A mapping never runs on its own. A session runs it and says which database connection each table uses. The workflow runs the sessions in order.
  3. Sources and targets are descriptions, not data. A staging target is described again as a source for the next mapping, so the 3 mappings form a chain: raw → staging → marts.
